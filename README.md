# 🗂️ Archive System — Secure Document Management Platform

A secure document management and archiving platform featuring Role-Based Access Control (RBAC) and categorized document storage.

---

## 📌 Project Overview

Archive-System streamlines organizational document workflows by providing secure storage categories, user authentication, and granular permission structures to control who can view, upload, or manage sensitive files.

---

## 🛠️ Tech Stack & Architecture

* **Backend:** PHP, CodeIgniter Framework, Custom Controllers & Models
* **Frontend:** HTML5, CSS3, JavaScript, Responsive Layouts
* **Database & Security:** MySQL, Role-Based Access Control (RBAC), Secure Session Management
